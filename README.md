# The Pickleball Review: Beginner's Issue

匹克球新手入門特刊 · A bilingual (Traditional Chinese / English) beginner's guide to pickleball rules.

- Single self-contained `index.html`, no build step. Auto-detects `zh` / `en` (`?lang=en` or `?lang=zh` to force one; the toggle remembers your choice).
- Pages: cover, court and gear, three golden rules, the serve, scoring, an interactive doubles-rotation diagram, skills and faults, Coach's Corner.
- Rules were checked against the 2026 USA Pickleball Official Rulebook; sources are listed on the last page.
- Jump to a page with `#1` to `#8`. Keyboard: left / right arrows.
